# ⚡ نیرا

**دستیار هوش مصنوعی شخصی برای تلگرام، که به‌طور کامل روی Cloudflare Workers اجرا می‌شود.**

[![Cloudflare Workers](https://img.shields.io/badge/Cloudflare-Workers-f38020.svg)](https://workers.cloudflare.com)

نیرا ربات تلگرام شما را به هر سرویس هوش مصنوعی‌ای که انتخاب کنید متصل می‌کند: OpenAI، Anthropic، یا هر سرویس سازگار با OpenAI (OpenRouter، Groq، Ollama و…). کل سامانه یک پروندهٔ Worker است؛ بدون مرحلهٔ ساخت، بدون کارسازی که نگهداری کنید و بدون فریم‌ورکی که باید یاد بگیرید. کلیدهای API شما رمزگذاری می‌شوند و بقیهٔ داده‌ها در D1 و KV کلادفلر می‌ماند.

## ✨ امکانات

- **🚀 بدون زیرساخت** — یک پروندهٔ Worker، یک پایگاهٔ دادهٔ D1 و یک فضای KV. نه کارسازی، نه ساخت پروژه.
- **🔀 هر سرویس‌دهنده‌ای** — API سازگار با OpenAI (با آدرس پایهٔ دلخواه) و Anthropic؛ پاسخ‌ها به‌صورت جریانی می‌آیند و همزمان در گفتگو ویرایش می‌شوند.
- **👥 اتصال‌های چندگانه** — مدیر مدل‌های سراسری تعریف می‌کند؛ کاربران هم می‌توانند اتصال شخصی بسازند، در هر گفتگو مدل عوض کنند و مدل پیش‌فرض شخصی تعیین کنند.
- **🔐 کلیدهای رمزگذاری‌شده** — کلیدهای API با الگوریتم AES-256-GCM (با مشتق‌گیری HKDF برای هر مالک) رمزگذاری می‌شوند و هرگز به‌صورت متن ساده در پایگاهٔ داده ذخیره نمی‌شوند.
- **🛟 بازخودکار خودکار** — اگر اتصالی خطا بدهد یا timeouts شود، نیرا دوباره تلاش می‌کند و در بازهٔ زمانی مشخص به اتصال‌های فعال دیگر می‌رود.
- **🧠 حافظه** — حافظهٔ ماندگار برای هر کاربر با سه حالت (عادی، کمینه، خاموش)، فرمان‌های صریح `/remember` و `/forget`، و جمع‌بندی دوره‌ای خاطرات.
- **🎭 شخصیت‌ها** — سه شخصیت پیش‌فرض (عادی، صمیمی، شوخ) به‌علاوهٔ تا ۱۰ شخصیت سفارشی برای هر کاربر.
- **👥 پشتیبانی از گروه** — در گروه‌ها نیرا فقط وقتی پاسخ می‌دهد که نامش برده شود (Nyra / نیرا / نيرا) یا به یکی از پیام‌هایش پاسخ دهید؛ زمینهٔ گفتگو برای هر رشتهٔ پیام جداگانه نگهداری می‌شود.
- **🛡️ محدودیت نرخ و مسدودسازی** — محدودیت برای هر کاربر، هر گفتگو و هر مدیر، به‌علاوهٔ فهرست مسدود مدیر.
- **🛠️ پنل مدیریت** — مدیریت کاربران، گفتگوها، حالت گروه‌ها، اتصال‌ها و فهرست مسدود، و مشاهدهٔ آمار و وضعیت سامانه؛ همه به‌صورت دکمه‌ای داخل خود تلگرام.

## 📋 پیش‌نیازها

- حساب [کلادفلر](https://dash.cloudflare.com) (پلن رایگان کافی است)
- توکن ربات تلگرام از [@BotFather](https://t.me/BotFather)
- کلید API از یک سرویس هوش مصنوعی (سازگار با OpenAI یا Anthropic)
- [Node.js](https://nodejs.org) و ابزار خط فرمان [Wrangler](https://developers.cloudflare.com/workers/wrangler/)

## 🚀 راه‌اندازی

### ۱. ساخت ربات

به [@BotFather](https://t.me/BotFather) پیام دهید، دستور `/newbot` را بفرستید و توکنی را که می‌دهد نگه دارید.

### ۲. ساخت فضای ذخیره‌سازی

```bash
wrangler d1 create nyra
wrangler kv namespace create KV
```

مقادیر `database_id` و `id` فضای KV را از خروجی در `wrangler.toml` وارد کنید.

### ۳. تنظیم اسرار

```bash
wrangler secret put TELEGRAM_BOT_TOKEN   # توکن @BotFather
wrangler secret put TELEGRAM_SECRET      # openssl rand -hex 32
wrangler secret put ENCRYPTION_KEY       # openssl rand -base64 32
```

شناسهٔ تلگرام خود را به‌عنوان مدیر در بخش `[vars] → ADMIN_IDS` فایل `wrangler.toml` وارد کنید (برای چند مدیر با کاما جدا کنید).

### ۴. انتشار

```bash
wrangler deploy
```

### ۵. ثبت وب‌هوک

یک بار این نشانی را باز کنید (میزبان و رمز را با مقادیر خودتان جایگزین کنید):

```
https://<your-worker>.workers.dev/setup?secret=<TELEGRAM_SECRET>&url=https://<your-worker>.workers.dev/webhook
```

پاسخ JSON با `"ok": true` یعنی نیرا بالا آمده است. ربات را در تلگرام باز کنید و `/start` بفرستید.

### ۶. اتصال مدل

در گفتگوی خصوصی با ربات، وارد `/admin` ← **Connections** شوید و یک سرویس‌دهنده اضافه کنید (سازگار با OpenAI به‌همراه آدرس پایه، یا Anthropic)، سپس کلید API و نام مدل را وارد کنید. تست را همان‌جا بزنید و مدل را به‌عنوان پیش‌فرض سراسری انتخاب کنید.

## ⚙️ پیکربندی

| متغیر | وضعیت | توضیح |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | ✅ | توکن ربات از @BotFather |
| `TELEGRAM_SECRET` | ✅ | رمزی که تلگرام با هر فراخوانی وب‌هوک می‌فرستد؛ دروازهٔ دسترسی `/setup` هم هست |
| `ENCRYPTION_KEY` | ✅ | کلید ۳۲ بایتیِ رمزگذاری‌شده به base64 برای رمزگذاری AES-256-GCM کلیدهای API |
| `ADMIN_IDS` | توصیه‌شده | شناسه‌های تلگرام مدیران، جداشده با کاما |
| `TELEGRAM_BOT_ID` / `TELEGRAM_BOT_USERNAME` | اختیاری | هویت کش‌شدهٔ ربات؛ در صورت خالی‌بودن خودکار دریافت می‌شود |

اتصال D1 با نام `DB` و KV با نام `KV` است (در `wrangler.toml`). ساختار پایگاهٔ داده در نخستین استفاده به‌طور خودکار ساخته و به‌روزرسانی می‌شود.

## 🔐 نکات امنیتی

- پیام‌های وب‌هوک بدون `TELEGRAM_SECRET` پذیرفته نمی‌شوند و مقایسهٔ رمز به‌صورت زمان ثابت انجام می‌گیرد.
- کلیدهای API با AES-256-GCM و کلیدهایی رمزگذاری می‌شوند که از `ENCRYPTION_KEY` شما برای هر مالک مشتق شده‌اند.
- مسیر `/setup` محدودیت نرخ دارد و فقط نشانی‌هایی روی همان میزبان را می‌پذیرد.
- اسرار محلی در پروندهٔ `.dev.vars` نگهداری می‌شوند (در git نادیده گرفته می‌شود) — نمونه در `.dev.vars.example`.
- اگر `ENCRYPTION_KEY` تنظیم نشده یا نامعتبر باشد، Worker درخواست‌ها را پردازش نمی‌کند.
