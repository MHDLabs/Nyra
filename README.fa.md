## وضعیت پروژه

نیرا در حال ساده‌سازی است تا تجربه‌ای تلگرام‌محور با فقط یک مدل هوش مصنوعی مرکزی داشته باشد. شاخهٔ فعلی main هنوز کدهای قدیمی را دارد؛ این تغییر مستندات، محدودهٔ نسخهٔ هدف را مشخص می‌کند و به‌تنهایی قابلیت‌های اجرایی را حذف نمی‌کند.

سند اصلی نیازمندی‌های نسخهٔ بعدی: [محدودهٔ محصول](docs/PRODUCT-SCOPE.md).

## مسیر محصول

- فقط یک آدرس API سازگار با OpenAI و یک مدل، با تنظیم مرکزی توسط مدیر.
- بدون کلید API شخصی کاربران، اتصال‌های متعدد، سیستم چندمدلی یا Route Management.
- حفظ گفتگوی تلگرام، حافظه، شخصیت‌ها، دستورالعمل‌های سفارشی، جست‌وجوی وب، ورودی تصویرِ پشتیبانی‌شده و گروه‌ها.
- **پنل وب مدیریت باقی می‌ماند** و از مسیر /admin-panel در دسترس خواهد بود.
- Mini App، یادآورها، تشخیص گفتار و تبدیل متن به گفتار حذف می‌شوند.

نکتهٔ مهم: Mini App و پنل وب مدیریت دو بخش جدا هستند. حذف Mini App به معنی حذف پنل وب نیست؛ فایل‌های public/admin-panel/ و مسیرهای مربوط به پنل باید حفظ شوند.

## معماری

نیرا یک Cloudflare Worker مبتنی بر TypeScript است. پیام‌های تلگرام از وب‌هوک وارد صف می‌شوند و در Worker پردازش می‌شوند. D1 برای داده‌های پایدار و KV برای وضعیت کوتاه‌مدت استفاده می‌شود. فایل‌های ایستای پنل وب مدیریت نیز از طریق Cloudflare Assets سرو می‌شوند.

| مسیر | کاربرد |
| --- | --- |
| src/ | کد اصلی Worker، پردازش تلگرام، هوش مصنوعی و پایگاه داده |
| src/admin-panel/ | مسیرها و API پنل وب مدیریت |
| public/admin-panel/ | فایل‌های پنل وب؛ باید باقی بمانند |
| types/ | قراردادهای TypeScript |
| test/ | آزمون‌ها |
| .specify/ | تنظیمات GitHub Spec Kit و قانون اساسی پروژه |
| .pi/prompts/ | فرمان‌های Pi برای گردش‌کار Spec Kit |
| docs/PRODUCT-SCOPE.md | نیازمندی‌ها و معیارهای پذیرش نسخهٔ هدف |

## توسعه

Node.js 22 و فایل lock مخزن را استفاده کنید:

~~~bash
npm ci
npm run typecheck
npm run typecheck:worker
npm run typecheck:web
npm run test:all
./node_modules/.bin/wrangler deploy --dry-run
~~~

بسته به تغییر، آزمون‌های مرتبط را اجرا کنید. بدون درخواست صریح، روی Worker اصلی استقرار انجام ندهید.

## پیکربندی

شاخهٔ فعلی هنوز از سیستم قدیمی اتصال به سرویس‌دهنده‌ها استفاده می‌کند. ورودی‌های استقرار فعلی در .dev.vars.example و wrangler.toml هستند. پیکربندی تک‌مدلی نسخهٔ هدف در [محدودهٔ محصول](docs/PRODUCT-SCOPE.md) تعریف شده و هنوز در کد اجرا نشده است.

برای مشارکت، ابتدا [راهنمای عامل‌ها](AGENTS.md)، [مشارکت](CONTRIBUTING.md) و [سیاست امنیت](SECURITY.md) را بخوانید.
